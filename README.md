# Página personal de Francisco

Página personal estática con perfil, formación, habilidades y proyectos.

https://FranGuerreroH.github.io/pagina-personal/site

## Cómo ejecutar

Necesitas Node.js 22 o superior. Instala las dependencias con `npm ci` y ejecuta `npm test` para validar el HTML y los tests. Usa `npm start` para servir el sitio localmente en http://localhost:8080.
